# Himalayan Expeditions Analysis | Power BI

## Project Overview

This project analyzes historical Himalayan mountaineering expedition data using Microsoft Power BI. It focuses on expedition trends, climber participation, peak analysis, climbing success rates, fatalities, and supplemental oxygen usage through interactive visualizations.

## Project Objectives

- Analyze historical Himalayan expedition trends.
- Identify popular climbing destinations and peaks.
- Examine climber participation and expedition outcomes.
- Compare climbing success rates across different peaks.
- Analyze expedition-related fatalities.
- Explore the relationship between mountain altitude and oxygen usage.
- Create an interactive dashboard for data exploration and visualization.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV / Excel dataset

## File Descriptions

- `README.md` – Provides an overview of the project, objectives, tools, and instructions for using the repository.
- `Himalayan_Expeditions_Report.pdf` – Contains the detailed project report documenting the analysis and dashboard development.
- `dataset.zip` – Contains the dataset used for data preparation, analysis, and visualization.
- `himalayas.pbix` – Contains the Power BI dashboard, data model, and report visualizations.

## How to Use

1. Clone or download this GitHub repository.
2. Extract `dataset.zip` to access the dataset.
3. Install Microsoft Power BI Desktop.
4. Open `himalayas.pbix` in Power BI Desktop.
5. Update the data source path if required.
6. Refresh the data and explore the interactive dashboard.
